# 工程招标&在建项目线索采集器（代码版）

豆包本地电脑模式代码型技能，结合 Playwright 自动化脚本 + AI 智能分析，采集政府工程公示项目线索，适配柴油发电机组销售获客。

## 功能特点
- ✅ 自动化翻页、提取页面内容，比纯提示词更稳定
- ✅ 自动过滤绿化、亮化、纯设计监理、停工烂尾等无效项目
- ✅ 提取字段：项目名称、业主、总包、施工单位、地址、联系人、电话
- ✅ 导出 CSV 表格，可直接用 Excel 打开
- ✅ 低速访问，遇验证码自动暂停等人工处理

## 环境要求
- Windows 电脑
- Python 3.8+（[下载地址](https://www.python.org/downloads/)）
- 豆包 PC 客户端，开启本地电脑权限

## 安装方式
打开豆包 PC 端，切换到【本地电脑】模式，发送：

```
帮我安装github上的【zhengying0608/yingzheng-123-home】技能，用于本地电脑模式采集工程招标、在建项目线索，确认结构后安装到本地技能目录。
```

## 使用方式
安装完成后，直接大白话提问：

```
帮我查找榆林市所有煤矿项目
帮我查找西安市所有在建项目
帮我查找延安市近60天的厂房项目
```

## 首次使用说明
第一次运行时，Agent 会自动安装 Python 依赖（playwright、pandas）和浏览器组件，需要几分钟时间。后续使用直接调用即可。

## 目录结构
```
yingzheng-123-home/
├─ SKILL.md           # 技能定义和调度规则
├─ README.md          # 本说明文件
├─ requirements.txt   # Python 依赖列表
└─ scripts/
   └─ crawler.py      # Playwright 自动化采集脚本
```

## 注意事项
- 本技能仅采集政府公开公示信息，不爬取商业企业查询平台
- 联系人、电话不是所有公示都有，没有会标注【无公示信息】
- 遇到验证码会自动暂停，需要你手动滑动验证后继续
- 单次最多采集50条，避免触发网站反爬
